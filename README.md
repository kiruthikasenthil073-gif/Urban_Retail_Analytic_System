# Job-Market-Skill-Analyzer

A Python project that analyses job posting skills, identifies popular skills, and generates reports using data structures and file handling.

**Objective:**

The purpose of this project is to analyse skills commonly required in data and analytics job postings using Python. The program stores job information, allows users to add new job postings, processes skill data, and generates useful insights about skill demand in the job market.

**Implementation:**

A dictionary was used to store job posting information, including Job ID, Role, Company, and Skills. The program uses loops, functions, lists, sets, dictionaries, lambda expressions, and file handling techniques to manage and analyse the data.

**Key features include:**

•	Displaying job postings in a readable format.

•	Adding new job postings with automatically generated Job IDs.

•	Cleaning and normalising skill data using a custom function.

•	Extracting skills and calculating their frequencies.

•	Searching jobs based on a specified skill.

•	Identifying common skills and related job roles.

•	Generating statistics such as total jobs, unique skills, and Python-related jobs.

•	Saving cleaned job data and skill frequency reports to external files.

**Result**

The program successfully identifies the most frequently requested skills across job postings and provides insights into current job market trends. Skills such as Python, SQL, Excel, and Machine Learning appear frequently among data-focused roles. The output files provide a structured format for further analysis and reporting.

**Conclusion**

This project demonstrates the practical use of Python data structures, functions, text processing, file handling, and basic data analysis techniques. It provides a simple yet effective tool for analysing skill requirements in job postings and understanding industry demand for technical skills.
