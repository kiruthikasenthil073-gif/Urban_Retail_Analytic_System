# Urban Retail Analytic System

Module 1 - Python Project using Google Colab

## Project Description
This project is a simple Urban Retail Analytic System built in Python.
It checks stock, generates tracking numbers, and manages inventory.

## Files in this Repository
- urban_retail_analytic_system.ipynb - Main Colab Notebook with code and outputs
- inventory_utils.py - Helper functions for inventory
- audit_log.txt - Audit log for stock checking

## How to Run
1. Open the .ipynb file in Google Colab
2. Click Runtime > Run All
3. Check the output
